5. INSTRUCTIVO DE EJECUCIÓN

El presente apartado describe de forma detallada los requerimientos técnicos y los procedimientos metodológicos para realizar el despliegue del sistema ActividadesExtraPortal, su compilación dentro del entorno de desarrollo de Microsoft Visual Studio 2022 y la posterior inicialización de sus servicios.

5.1 Requisitos del Entorno de Trabajo

Previo a realizar la apertura de la solución, el desarrollador o auditor del proyecto debe validar que el equipo de computación cuente con los componentes de infraestructura y software indicados a continuación:

Componente Especificación y Versión Requerida
Sistema Operativo Microsoft Windows 10 o Windows 11 de 64 bits.
Entorno de Desarrollo (IDE) Microsoft Visual Studio 2022 (v17.10 o superior) con soporte para escritorio .NET.
SDK de .NET SDK de .NET 10.0 (Windows Desktop Runtime correspondiente).
Servidor de Base de Datos Microsoft SQL Server 2019 o superior (LocalDB, Express o superior).
Navegador Web Google Chrome (actualizado para su uso mediante WebDriver).

5.2 Configuración de la Base de Datos Relacional

El almacenamiento persistente del sistema se gestiona bajo el esquema de base de datos relacional GestionExtracurricular en Microsoft SQL Server. Para inicializar la base de datos local, realice el siguiente procedimiento:

  1. Inicie la consola de administración de base de datos SQL Server Management Studio (SSMS) o Azure Data Studio.
  2. Establezca conexión con su motor de base de datos local (por ejemplo: localhost, . o (localdb)\MSSQLLocalDB).
  3. Abra el archivo de script SQL de creación de objetos y relaciones ubicado en la ruta del repositorio: Resources/proyecto.sql.
  4. Ejecute el script completo presionando la tecla F5 o haciendo clic en el botón "Ejecutar". Esto creará la base de datos y todas las tablas del esquema.
Nota sobre la cadena de conexión:

La conexión a la base de datos se define en la propiedad de clase del archivo DatabaseConnection.cs (línea 9). En caso de usar una instancia de SQL Server que no sea localhost, modifique el servidor en la cadena de conexión:

private readonly string connectionString = @"Server=TU_SERVIDOR;Database=GestionExtracurricular;Trusted_Connection=True;TrustServerCertificate=True;";

5.3 Apertura del Proyecto en Visual Studio

El proyecto incorpora la especificación XML moderna de soluciones de Visual Studio (.slnx), la cual reduce la sobrecarga de metadatos de los antiguos archivos .sln convencionales.

  1. Abra Microsoft Visual Studio 2022.
  2. Seleccione la opción "Abrir un proyecto o una solución".
  3. Navegue a la carpeta del repositorio y elija el archivo de solución de nueva generación ActividadesExtraPortal.slnx, o en su defecto, el archivo del proyecto ActividadesExtraPortal.csproj.
  4. Presione "Abrir". Visual Studio cargará el árbol de archivos en el Explorador de Soluciones.

5.4 Restauración de Paquetes NuGet y Compilación

El aplicativo requiere un conjunto de dependencias externas alojadas en el gestor público NuGet. Por defecto, Visual Studio resolverá las dependencias al iniciar el proceso de compilación.

Librerías incorporadas:

  • MaterialSkin.2 (v2.3.1): Kit de diseño gráfico para formularios bajo las especificaciones de diseño de Material.
  • Selenium.WebDriver (v4.45.0): Módulo de control del navegador para la automatización web.
  • Microsoft.Data.SqlClient (v7.0.2): Conector para la consulta de datos en SQL Server.

Compilación de la Solución:

  1. Si desea restaurar los paquetes manualmente, haga clic derecho sobre el nodo de la solución en el Explorador de Soluciones y seleccione "Restaurar paquetes NuGet".
  2. Proceda a compilar la solución desde el menú superior Compilar > Compilar solución o mediante la combinación de teclas rápidas Ctrl + Shift + B.
  3. La ventana de "Salida" confirmará la generación satisfactoria del binario ejecutable ActividadesExtraPortal.exe en la ruta local del proyecto.

5.5 Proceso de Ejecución y Flujo de Operación

Para realizar la puesta en marcha de la aplicación y comprobar su lógica de negocio de extremo a extremo, ejecute los siguientes pasos:

  1. En Visual Studio, presione la tecla F5 o haga clic en el botón de reproducción verde Iniciar para comenzar la depuración.
  2. Módulo de Scraping Activo (Selenium): La aplicación abrirá automáticamente una instancia de control de Google Chrome apuntando al Portal Web estudiantil institucional (https://admacad.udb.edu.sv/PortalWeb/).
  3. Autenticación del Estudiante: Ingrese el Carnet y contraseña válidos en los campos del formulario dentro del navegador web automatizado.
  4. Extracción de Perfil: Al iniciar sesión de manera exitosa, el código inyectará JavaScript para leer los datos académicos del DOM y descargar la fotografía de perfil. Posteriormente, la ventana de Google Chrome automatizada se cerrará automáticamente.
  5. Dashboard de Escritorio: La aplicación registrará o actualizará los datos recuperados en SQL Server y presentará el panel final de administración del estudiante en base a MaterialSkin, permitiendo interactuar con los submódulos de Cursos, Asociaciones y Actividades Deportivas o Artísticas.
